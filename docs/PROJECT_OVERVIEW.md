# PROJECT_OVERVIEW — Foot Fianara

## Vision

Site web gratuit permettant aux fans de football de Fianarantsoa de suivre le championnat local : résultats, classements, calendrier, clubs et joueurs. Remplace la diffusion des résultats sur la seule page Facebook.

## Inspiration

Style Premier League (lisibilité des données, cartes de match, classement). On reprend la clarté, pas les fonctionnalités : pas de direct, pas de paiement, pas de notifications.

## Cadre

- Lieu : Fianarantsoa, stade Ampasambazaha (autres stades ajoutables par l'admin).
- Saison semestrielle, début en janvier.
- 3 divisions (D1, D2, D3) de 12 clubs au départ (modifiable).
- Langue : français. Mobile first (4G, smartphones).
- Développeur : le client seul, assisté par Claude. Stack : Next.js, hébergement gratuit au départ.

## Utilisateurs

- **Fans (public)** : consultent, sans compte.
- **Super admin** (le client), **admin**, **assistant admin** : voir USER_ROLES.md.

## Objectifs

1. Principal : suivre matchs et infos du championnat.
2. Principal : présenter chaque club et chaque joueur.
3. Secondaire : actualités, sponsors, annonces officielles.

## Principe directeur

Simplicité et fiabilité. Tout ce qui n'est pas dans REQUIREMENTS.md n'est pas dans le projet.
